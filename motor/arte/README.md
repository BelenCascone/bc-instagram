# Arte + compu

Placas con pinturas clásicas de dominio público (Munch, Vermeer, Miguel Ángel, retrato del s. XVIII) + un tip de informática.

`npm i @fontsource/playfair-display @fontsource/caveat @fontsource/inter playwright` y después `node render.js` (o `node render.js grito` para una sola). Salen en `out/` a 1080x1350.
