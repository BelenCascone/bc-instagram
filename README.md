# bc-instagram

Imágenes y videos **ya publicados** en [@bc.informatica.pna](https://www.instagram.com/bc.informatica.pna/), más el motor de plantillas de BC Informática.

- `media/AAAA-MM-DD-tema/`: piezas publicadas. Instagram las lee desde acá. Se suben solo el día de la publicación.
- `motor/`: plantillas HTML que se convierten a imagen (Node + Playwright, tipografías Anton, Inter y JetBrains Mono, íconos pixel art propios).

Los borradores y el calendario no están acá: viven en el Project privado "Instagram BC".
